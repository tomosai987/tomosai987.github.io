Health API to calendar

本ツールは、開発者本人が個人利用のために作成した Google Apps Script です。Google Health API から本人の運動・歩数・睡眠などの記録を読み取り、本人の Google カレンダーに日次の記録として書き込みます。

プライバシーポリシー / Privacy Policy

本ツールは、Google Health API から取得したデータを本人の Google カレンダーへの書き込みのみに使用します。取得したデータを第三者に提供・販売・共有することはなく、広告目的にも使用しません。データは Google Apps Script の実行中にのみ処理され、本人のカレンダー以外の外部サーバーには保存しません。

This tool is a personal-use Google Apps Script. Data obtained from the Google Health API is used solely to write daily records to the developer's own Google Calendar. The data is never sold, shared with third parties, or used for advertising, and is not stored on any external server.

本ツールによる Google ユーザーデータの使用と移転は、Limited Use 要件を含む Google API Services User Data Policy に準拠します。

利用規約 / Terms

本ツールは開発者本人のみが利用するものであり、一般には提供していません。
